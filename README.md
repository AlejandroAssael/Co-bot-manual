# Co-bot-manual
Welcome to Co-Bot!

Welcome to Co-Bot, your friendly robotic sidekick for learning all things robotics and programming! Co-Bot is a 6-DOF robotic arm designed to be more than just a display — it’s an interactive learning companion for curious minds who want to dive into the world of motors, kinematics, and microcontrollers. Open up the step-by-step instruction guide to figure out how to connect your computer to the Co-Bot and start programming!
